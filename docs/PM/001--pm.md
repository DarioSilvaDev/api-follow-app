El error más común

La mayoría define los módulos según la base de datos:

Usuarios

Vehículos

Clientes

Talleres

Órdenes

Presupuestos

Eso es un error.

Los módulos deberían representar capacidades de negocio, no tablas.

Nuestra visión

Antes de definir el MVP, quiero escribir lo que, para mí, será el manifiesto del producto.

Nuestra plataforma centraliza la historia clínica digital de los vehículos y conecta a propietarios, talleres y especialistas en un ecosistema colaborativo de mantenimiento y reparación.

Eso implica que tenemos dos productos en uno:

Una plataforma para propietarios de vehículos.
Una plataforma para talleres.

Y ambos comparten el mismo activo: el vehículo.

Los tres Workspaces del producto

Todo el sistema se organiza alrededor de tres espacios.

Platform Workspace

Administra el SaaS.

Personal Workspace

Administra la relación entre el propietario y sus vehículos.

Workshop Workspace

Administra la operación diaria del taller.

Todo lo demás cuelga de alguno de estos tres.

El MVP no debe tener módulos

Debe tener capacidades

Yo las agruparía así.

Dominio 1 — Identity & Access

Este módulo ya está bastante definido.

Responsabilidad:

Saber quién está usando la plataforma y desde dónde.

Incluye:

Registro.
Login.
Recuperación de contraseña.
Active Context.
Roles.
Permisos.
Invitaciones.
Membresías.
Auditoría de acceso.

Este módulo casi nunca cambia.

Dominio 2 — Vehicle Registry

Responsabilidad:

Administrar la identidad del vehículo.

Incluye:

Alta de vehículo.
VIN.
Patente.
Marca.
Modelo.
Motor.
Año.
Fotos.
Propietarios.
Transferencias.
Accesos.

No incluye mantenimiento.

Dominio 3 — Vehicle Health Record ⭐

Este es nuestro diferencial.

Incluye:

Care Episodes.
Diagnóstico.
Evidencias.
Timeline.
Garantías.
Recomendaciones.
Historial completo.

No administra talleres.

Administra la salud del vehículo.

Dominio 4 — Workshop Operations

Este módulo representa el negocio del taller.

Incluye:

Recepción.
Atención.
Presupuestos.
Órdenes.
Mano de obra.
Estados.
Entrega.
Control de calidad.

No administra vehículos.

Administra trabajo.

Dominio 5 — Customer Management

Nosotros no.

El taller puede tener clientes que todavía no usan la plataforma.

Ejemplo.

Juan Pérez

No tiene usuario.

Pero existe como cliente.

Cuando se registra.

Simplemente se vincula.

Este módulo incluye:

Clientes.
Contactos.
Historial.
Vehículos asociados.
